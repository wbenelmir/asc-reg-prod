{% load i18n %} {% comment %} Participant Appearance menu (responsive themes), beside the language control in the participant headers. A disclosure button opens a small panel holding one native radio group: the browser provides the labels, the checked state and arrow-key selection. `static/js/asc-appearance.js` reveals the control, marks the current theme, applies a choice immediately to (no request, no navigation, no form) and returns focus to the button when the panel closes. The radios belong to no form, so nothing here is ever submitted. Without JavaScript the control stays hidden and the page keeps the standard presentation. `compact`: the workspace header (more controls) shows only the colour dot below 1400 px; the name stays the button's accessible name and tooltip. Theme identifiers (aurora, fresh, glass, color) are the only values the script keeps on the device. {% endcomment %}
