{% load i18n %} {% comment %} Shared confirmation dialog for destructive or consequential commands (UI/UX Completion Gate F6; static/js/asc-enhance.js). One instance per page, rendered by base.html. A form opts in with `data-confirm` (the question) and optionally `data-confirm-title`, `data-confirm-action` (the confirm button label; defaults to the submit button's text) and `data-confirm-tone="primary"` for a non-destructive consequential action. Opening the dialog never submits anything: the form is submitted only by its confirm button, through the browser's own form submission, so CSRF, POST-only and every server-side permission check apply unchanged. Escape and "Go back" close it and return focus to the button that opened it. {% endcomment %}
