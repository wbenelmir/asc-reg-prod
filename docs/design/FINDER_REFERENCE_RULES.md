# Finder Reference Rules

The purchased Finder package remains on the developer's local machine and is not included in this workspace. The developer may attach a specific file, screenshot, or asset when a current UI task needs it.

## Allowed

- Inspect only the specific files or images explicitly attached for the active UI component.
- Adapt licensed Bootstrap-compatible patterns into project-owned Django templates and components.
- Reuse licensed assets only when the source and use are recorded.
- Consult Finder RTL styles while implementing project-owned RTL behavior.

## Prohibited

- Do not adopt Finder as the application architecture.
- Do not introduce a React SPA, Finder routing, Finder state management, or unrelated dependencies.
- Do not copy entire pages when a smaller component adaptation is sufficient.
- Do not request or scan the complete local Finder package.
- Do not modify the original local Finder files.
- Do not copy the Finder package into the application repository.

Record every adapted component or reused asset in `finder_inventory.md`.
