# Version 1.1 — UI work package 02: one conference header

The conference logo, full conference name and 2026 are now a single identity
inside the existing application header. This supersedes the separate brand
strip and additional public authentication artwork introduced by UI package 01.

All public, workspace, wizard, operations, entry and error shells share the
same identity component. A default base header also covers pages without a
shell-specific header. The logo is decorative beside the visible conference
name, preserving an accessible link name without repeated image text.
The layout wraps navigation and controls at narrow widths, supports RTL, and
retains the original logo proportions. The stylesheet URL has a revision query
to refresh browser caches when the updated asset is deployed.

No migration or dependency change is introduced. Field alignment, participant
status guidance and receipt-email lookup from UI package 01 remain in effect.

Apply this update after UI package 01, preserving relative paths. Serve the
updated stylesheet and templates together. Use the existing static collection
and process refresh procedure on deployed environments. Run the existing local
gate in the prepared Python 3.14/PostgreSQL environment before release approval:

```bash
uv run --env-file .env python scripts/check.py all
```

Check EN/FR/AR at phone, tablet and desktop widths: exactly one conference logo
per page, prominent event name/year inside the header, usable navigation,
readable language/session controls, and no horizontal page overflow. Check
public authentication, participant passes/workspace, wizard and static errors.
